# Слепой свидетель

Кооперативный детектив на 3–5 человек. Дело одно на всех, но **каждый игрок видит
только свою часть**: картограф — карту и время, писарь — алиби, очевидец — показания,
лекарь — тело. Истина хранится в коде сервера и не уходит ни одному клиенту.

Общаться надо словами — вживую или в Discord. Игра только даёт каждому свою половину правды.

## Как играть

1. Один человек запускает сервер и присылает остальным ссылку.
2. Все входят по одной ссылке, вводят имена, создатель нажимает «Начать дело».
3. Каждый читает свои документы и прикладывает нужные к общему столу.
4. Когда версия готова — обвинение: имя плюс доказательства по трём линиям.

Победа — верный убийца и все три линии: место, время, оружие. Имя не то — дело
закрыто, настоящий убийца ушёл. Улики, помеченные в деле как ложные, прокурор
не принимает, но игроки этого не видят.

## Запуск

```bash
npm install
npm start
```

Откройте http://localhost:8080 — комната создастся сама, ссылка с номером комнаты
появится в адресной строке. Ссылку можно сразу дополнить именем:
`http://localhost:8080/#room=abc12&name=Аня`.

Чтобы зайти к друзьям, код комнаты вводится на экране входа, в поле «Код комнаты»
(например `abc12`). Пустое поле — своя новая комната. Код показывается в правом
верхнем углу комнаты.

Рядом с полем имени — режим входа: **игрок** получает пакет документов,
**ведущий** видит всё дело и открывает улики на столе, **наблюдатель** смотрит молча.

Переменные окружения:

| Переменная | По умолчанию | Зачем |
| --- | --- | --- |
| `PORT` | `8080` | порт |
| `DB` | `data/blind-witness.db` | база аккаунтов и статистики |
| `CASE` | случайное из `cases/` | зафиксировать дело по id |
| `AI_URL`, `AI_KEY`, `AI_MODEL` | — | необязательный слой ИИ для свидетелей |

## Роли

| Роль | Видит |
| --- | --- |
| Штурман | карту, отметки перемещений, время постов |
| Писарь | заявления, алиби, рапорты |
| Очевидец | показания и приметы |
| Лекарь | тело, время смерти, оружие |
| Архивист | судимости, долги, связи (при пяти игроках) |

При трёх игроках двое получают по два пакета. Один из пакетов может лгать —
игрок с ним об этом не знает.

## Дела

Три готовых дела в `cases/`: маяк на Ольховой косе, премьера в театре «Свеча»,
санаторий «Сосны». Комнате достаётся случайное.

Четвёртый источник — генератор: `cases/blocks/lighthouse.json` хранит блоки
(подозреваемые, места, время, оружие, шаблоны улик), а `server/blocks.mjs`
собирает из них новое дело на каждую комнату. Правда выбирается кодом,
улики подставляются в шаблоны, три из них ложные.

Своё дело можно собрать в редакторе: http://localhost:8080/editor — форма вручную
или готовый промт для модели. Редактор проверяет дело теми же правилами, что и движок.
Скачанный JSON положите в `cases/` и перезапустите сервер.

## Свидетели-боты

У подозреваемого есть кнопка «спросить». Свидетель отвечает только своими заранее
нарезанными фактами, поэтому выдать лишнее не может. Без ключа ИИ игра работает
так же — ответы просто суше. С ключом модель пересказывает тот же факт своими словами.

## Аккаунты

Регистрация по имени и паролю (scrypt, сессии в cookie). Гость тоже может играть.
Таблица компании считает сыгранные дела и победы, данные лежат в SQLite (`node:sqlite`,
без внешних зависимостей).

## Своё лицо

У залогиненного игрока в шапке есть кнопка «Своё лицо»: принимаются PNG, JPEG и WebP
до 200 КБ. Картинка подменяет пиксельный спрайт в списке игроков, в чате и у
подозреваемых. Хранится рядом с аккаунтом (`avatars`), отдаётся по имени
`GET /api/avatar/<имя>`; на Cloudflare это D1, локально — файлы в `data/avatars/`.
Гостям загрузка недоступна: лицо привязывается к аккаунту.

## Структура

```
server/
  index.mjs   http, websocket, api, статика
  room.mjs    состояние комнаты, карточки стола, обвинение
  case.mjs    загрузка дел и проекция по ролям
  verdict.mjs проверка обвинения
  bot.mjs     свидетели, необязательный ИИ
  editor.mjs  валидатор дел
  store.mjs   аккаунты и статистика на node:sqlite
client/
  index.html, app.js, style.css, avatar.js, editor.html, editor.js
cases/        три дела в JSON
scripts/      demo.mjs — наполнить комнату для проверки вида
test/         node --test
```
