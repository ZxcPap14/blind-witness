# Слепой свидетель — спецификация v1.0

Кооперативный детектив на 3–5 человек. Истина дела живёт только на сервере,
каждый игрок видит свою часть и обязан объяснять её словами — в Discord.

---

## Решения (из опроса)

| Вопрос | Решение |
| --- | --- |
| Компания | 3–5 игроков, ПК, голос в Discord |
| Вечер | несколько дел подряд |
| Длина дела | 20+ минут (реально 25–30 при трёх линиях) |
| Правда | случайная, каждый запуск новая |
| Подозреваемые | 4 при трёх игроках, 6 при четырёх-пяти |
| После финала | полный разбор: кто кем был, у кого какие улики |
| Роли | свои названия, раздаёт сервер, двойной пакет — норма |
| Ведущий | два режима: играет без пакета / наблюдает отдельно |
| Врун | есть, сам не знает, что его документы лгут |
| Улики | только свои, прикладывание бесплатное |
| Вердикт | верное имя + все три линии (место, время, оружие) |
| Ложные улики | 2–3 за дело |
| Провал | окончательный, второй попытки нет |
| Стол | доска с перетаскиванием карточек |
| Заметки | приватные есть, кнопка «подозреваю X» есть |
| Таймер | для темпа, без штрафа |
| Раунды | свободный поток до обвинения |
| Таблица компании | нужна, между партиями |
| Аватары | пиксельные 2D, простая анимация, свои картинки, видны везде |
| Экраны | поддержка всего, включая телефоны и 1280×720 |
| Публикация | открытый GitHub, аккаунты логин+пароль |
| Переподключение | да, в ту же роль и место |
| Дела | JSON + редактор (вручную или промтом для ИИ) |
| Хостинг | Cloudflare, без своего сервера |
| Дел к первой версии | 3 |
| ИИ | только свидетели-боты; игра полностью работает без ИИ |
| Порядок работ | доска → аватары → аккаунты → редактор → боты |

## Роли

Пять пакетов документов. Названия меняются одной строкой в конфиге.

| Роль | Что видит | Чего не видит |
| --- | --- | --- |
| **Штурман** | карту, отметки перемещений, время прохода постов | тела, оружия |
| **Писарь** | заявления, алиби, рапорты | тел, карт |
| **Очевидец** | показания, приметы (часть врёт) | официальных документов |
| **Лекарь** | тело, время смерти, класс оружия | мотивов и лиц |
| **Архивист** | судимости, долги, связи | как всё было на самом деле |

При 3 игроках двое получают по два пакета, при 5 в игру входит Архивист.

**Сказочник** — не отдельный игрок, а свойство: один из пакетов помечен как лгущий.
Игрок с ним не знает, что документы врут, и защищает их как настоящие.

## Правда и генерация

Полный ИИ-генератор не используется. Правда собирается кодом из подготовленных блоков:

```
убийца  × место  × время  × оружие  →  набор улик по ролям
```

У каждого блока заранее прописано, что он доказывает (`proves`). Поэтому дело
решаемо всегда: код знает, кто убийца, и выдаёт нужное число правдивых улик на каждую линию.

Ложные улики (2–3) добавляются с `truthful: false`: прокурор их не принимает,
но игроки этого не видят.

## Вердикт

```
имя не то                        → провал, дело закрыто
не все три линии доказаны        → прокурор вернул дело, продолжаете
имя верное и три линии           → победа, оценка A/B/C по числу раундов обсуждения
```

## Режимы

1. **Без ведущего** — никто не знает правды, роли раздаёт сервер.
2. **Ведущий-игрок** — шестой участник без пакета: видит дело целиком, может выдавать подсказки и открывать новые улики.
3. **Ведущий-наблюдатель** — отдельный вход, полная правда, управление темпом, в обсуждении не участвует.

## Стол

- Доска с карточками: документ прикладывается кнопкой и появляется карточкой, заметки пишутся от руки.
- Перетаскивание мышью и пальцем, координаты в процентах — раскладка не ломается при смене экрана.
- Приватная заметка видна только автору, остальные видят «закрытая карточка».
- Кнопка «подозреваю X» помечает подозреваемого цветом автора, без обвинения.
- Таймер показывает время с начала дела, ничего не блокирует.

## Аккаунты и статистика

Логин и пароль, сессия в cookie. Хранится: имя, аватар, число дел, средняя оценка,
история партий. Открытый GitHub, лицензия MIT.

## Редактор дел

- Ручной режим: форма с подозреваемыми, уликами и привязкой к линиям.
- Промт-режим: копируешь промт, вставляешь ответ модели, редактор проверяет формат.
- Валидатор обязателен: убийца среди подозреваемых, у каждой линии есть правдивая улика, ложных не больше трёх.

## Свидетели-боты

Бот получает не дело, а заранее нарезанные факты своего персонажа. Модель только
переформулирует их в реплику, поэтому выдать лишнее не может. Без ключа ИИ
свидетели просто выдают те же факты текстом — игра не меняется.

Вопрос задаётся кнопкой «спросить» у подозреваемого. Ответ выбирается по совпадению
слов вопроса с фактами; если совпадений нет — свидетель уходит от ответа.

Необязательный ИИ включается переменными окружения: `AI_URL`, `AI_KEY`, `AI_MODEL`.
Любая ошибка модели — молча отдаём исходный факт.

## Аватары

Пиксельные 2D, простая анимация (дыхание, моргание). Показываются в списке
подозреваемых, на столе и в чате. Свой аватар загружается картинкой.

## Технически

- **Прод:** Cloudflare Workers + Durable Objects (комната = объект), D1 (аккаунты и статистика), R2 (аватары и картинки дел).
- **Разработка:** локальный Node-сервер, тот же протокол, комнаты в памяти.
- Транспорт: WebSocket, сообщения JSON, состояние комнаты — один снапшот плюс точечные апдейты.
- Клиент: нативные ES-модули без сборки, Canvas для доски и аватаров.

## 0.2 — прод как полноценный сервер

- Аккаунты в D1: регистрация, вход, cookie-сессии, пароли через PBKDF2.
- Имя в комнате берётся из сессии, а не из сообщения: чужим именем не войти.
- Статистика и таблица компании считаются на проде, а не только на localhost.
- Редактор снова открыт: `/api/validate` отдаёт тот же валидатор, что на локалке.
- Гостевой вход остаётся: аккаунт нужен только для строки в таблице компании.

Не входит: режимы ведущего, случайная правда из блоков, загрузка своих
аватаров — это 0.3.

## Границы

- Никаких рейтингов, магазинов и монетизации.
- ИИ не обязателен ни для одной механики.
- Истина не покидает сервер: проверяется тестом, а не обещанием.
